常用接口

GET  /health
GET  /api/<kind>
POST /api/<kind>
GET  /api/entities/<id>
GET  /api/entities/<id>/versions   （历次对外发布版本）
POST /api/entities/<id>/actions

台站检修缺报补录复核：
  值班员 backfill           → revision_pending（原发布震级不变）
  复核员 approve_revision   → confirmed:true 后修订才对外生效
  复核员 reject_revision    → 驳回，原发布内容不变
